# પ્રશ્નપત્ર — Question Paper Generator (web app)

Live: https://prashnapatra.vercel.app/ (also https://mahaan2008.github.io/prashnapatra/)

This repository holds only the files of the online app (HTML/CSS/JS, fonts, icons).
Questions and papers are never stored here: each user logs in (email + password) and their data syncs through a private Supabase database.
